# محرّك ريلز أجمكان

إنتاج ريلز تيك توك لـ**أجمكان** — وجهة على البحر في الخبر، المنطقة الشرقية —
من صور درايف، بتصميم ثابت الهوية وكل ٣ أيام فكرة مختلفة.

<div dir="rtl">

## ما الذي يفعله

- يبني فيديو عموديًا ‎1080×1920‎ بـ‎30fps‎ جاهزًا للنشر.
- **مشهد افتتاح**: صورة رئيسية بحركة تقريب، عنوان عربي ضخم بخط كوفي، وسطر
  تمهيدي بلون الشمس من الشعار.
- **بطاقات مرقّمة**: لكل لقطة بطاقة زجاجية (ضبابية شفافة) فيها عنوان قصير
  وسطر وصفي، مع حركة Ken Burns مختلفة لكل صورة.
- **ختام**: خلفية بألوان العلامة، الشعار، «أجمكان»، الموقع، زر الحجز،
  ورقم التواصل **0535516054**.
- **لمسات ثابتة**: تدرّج لوني بهوية العلامة (ظلال زرقاء وإضاءات ذهبية)،
  شريط تقدّم، علامة مائية، فينييت، وحبيبات فيلمية خفيفة.
- يُخرج معه **صورة غلاف** و**نص المنشور** مع الهاشتاقات.

## التشغيل السريع

```bash
bash setup.sh
python3 -m reels demo          # عيّنة بصور تجريبية للتأكّد أن كل شيء يعمل
```

للإنتاج الحقيقي:

```bash
python3 scripts/fetch_drive.py --colab        # أو --from ~/مجلد/الصور
python3 -m reels check plans/cycle-001.json   # فحص الخطة والنص
python3 -m reels build plans/cycle-001.json   # الإخراج النهائي
```

النتائج في `out/`: ملف `.mp4` وصورة `.jpg` ونص `.txt`.

## بنية المشروع

| المسار | الدور |
|---|---|
| `brand/brand.json` | الهوية: الألوان، الخطوط، الموقع، رقم التواصل، نبرة الكتابة |
| `brand/fonts/` | خطوط عربية مرفقة (كوفي، المراعي، طجوال، القاهرة) |
| `reels/concepts.py` | مكتبة الأفكار الست (ماذا نقول) |
| `reels/styles.py` | فضاء التصميم (كيف يبدو) — مفاتيح تُركَّب بحرّية |
| `reels/catalog.py` | فهرس محتوى الصور والتحقّق من مطابقة النص لها |
| `reels/plan.py` | بنية «الخطة»: وصف الفيديو كاملًا في ملف JSON |
| `reels/scenes.py` | المشاهد: الافتتاح، البطاقات، الختام |
| `reels/typography.py` | التنضيد العربي (تشكيل، اتجاه، لفّ الأسطر) |
| `reels/imagefx.py` | التدرّج اللوني، الزجاج الضبابي، التدرّجات، الحبيبات |
| `reels/timeline.py` | الانتقالات والعناصر الثابتة فوق كل المشاهد |
| `reels/render.py` | التصدير إلى MP4 عبر ffmpeg |
| `plans/` | خطة كل دورة (يكتبها كلود كل ٣ أيام) |

## الخطة (`plans/cycle-XXX.json`)

كل ما يتغيّر بين حلقة وأخرى موجود في ملف واحد — لا حاجة للمساس بالكود:

```jsonc
{
  "cycle": 1,
  "concept": "reasons",            // مفتاح الفكرة من concepts.py
  "topic": "أجمكان",
  "headline": "٥ أسباب\nتخليك تجي أجمكان",
  "kicker": "لماذا أجمكان",
  "subline": "على بحر الخبر — قريب منك أكثر مما تتخيّل",
  "cta": "احجز جلستك الآن",
  "hero_photo": "assets/incoming/DSC03119.JPG",
  "shots": [
    { "photo": "assets/incoming/DSC03144.JPG",
      "title": "البحر قدّامك",
      "body": "جلسة على الرمل والموج على مرمى خطوة" }
  ],
  "caption": "…نص المنشور…",
  "hashtags": "#أجمكان #الخبر …"
}
```

`python3 -m reels scaffold 2` يولّد هيكل الدورة التالية بالفكرة الصحيحة.

## الأفكار الست (ماذا نقول)

1. **الأسباب** — «٥ أسباب تخليك تجي أجمكان»
2. **يوم على البحر** — من الصباح إلى الغروب
3. **الغروب** — نبرة شاعرية وإيقاع أبطأ
4. **أجواء العائلة** — لحظات مشتركة
5. **الدليل السريع** — نصائح عملية قبل الزيارة
6. **الدعوة** — إيقاع سريع يركّز على الحجز

## التصميم مختلف كل مرة (كيف يبدو)

الشكل ليس قالبًا ثابتًا. `reels/styles.py` يعرّف *فضاء* من المفاتيح — شكل
بطاقة النص (زجاج، شريط، مجرّد، شريطة، ركن)، موضع العنوان، شكل الترقيم، لون
التمييز، مؤشّر التقدّم، نوع الانتقال، سلّم الخطوط، قوّة التدرّج اللوني —
ومهارة [`ajmkan-reel-design`](.claude/skills/ajmkan-reel-design/SKILL.md)
تؤلّف منها تركيبة جديدة في كل دورة، مربوطة بطبيعة الصور نفسها، ولا يُسمح
لها بتكرار تركيبة سابقة.

كل قيمة خارج الحدود المسموحة تُرفض آليًا، فيبقى الابتكار داخل الهوية.

## النص لا يخالف الصورة

قبل كتابة أي نص، تُقرأ صور درايف ويُسجّل محتواها في `assets/catalog.json`.
عند التحقّق يقارن المحرّك كلمات النص بوسوم الصورة ويرفض الإخراج عند
التناقض:

```
تناقض: النص يذكر «بحر» بينما الصورة «shot1.jpg» موسومة بـ [غرفة، مبنى]
```
